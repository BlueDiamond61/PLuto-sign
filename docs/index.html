IPA contents

Edit Info.plist

Edit the complete property-list dictionary as JSON. Nested dictionaries, arrays, strings, booleans and numbers are preserved. Save changes to the in-memory IPA copy, then export it.

Changing Info.plist invalidates the IPA's existing code signature. The exported IPA is a modified package, not a signed or install-ready app. Re-signing must be completed through an authorized Apple workflow.

IPA Compatibility Checker

Package metadata, embedded library versions and architecture review

Choose a second IPA as a reference package to compare app and bundled-library versions. Use a trusted, newer copy of the same app as the reference. Without a reference, Pluto Sign can still inspect architecture coverage and package metadata, but cannot determine whether a version is current.

This is a static IPA package review only. It does not inspect live memory, calculate or update runtime offsets, patch executables, inject code or change the imported IPA.
