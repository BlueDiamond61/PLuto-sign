This web workspace prepares a request only. It does not run Apple's code-signing tools, modify signatures, install apps or produce a signed IPA. A selected-file check is not proof that a certificate and profile match. Actual signing must be completed through an authorized Apple workflow that validates the bundle ID, entitlements, profile expiry and distribution method.
