INSTALL THE HOME SCREEN SHORTCUT
On your iPhone using Safari
  1. Tap Download Home Screen Profile above.
  2. Tap Allow when iOS asks to download the configuration profile.
  3. Open Settings and tap Profile Downloaded.
  4. Review the profile and tap Install to add the Pluto Sign website shortcut.

Important: the .mobileconfig profile adds only a removable website shortcut. It does not install the native iOS app, add certificates, configure VPN or device management, sign apps, or make unsigned IPA packages installable. The iOS project is source code; the current automated artifact targets iOS Simulator and is not an installable iPhone IPA. Actual signing and device distribution require an authorized Apple workflow.
