INSIDE THE APP

View IPAs

⌕

IPA Archive Browser

Browse folders and search package paths for dylibs, frameworks, plists and readable text files.

Files & Imports

Import general documents from the iOS Files picker. IPA and provisioning files route to their dedicated sections.

⚿

Import Your Certificate

Bring your own password-protected P12/PFX identity. Pluto Sign validates the password and stores the file in iOS Keychain without retaining the password.

▧

Provisioning Profiles

Import your own .mobileprovision file and keep it in the app's private storage for signing preparation.

✓

Sign IPA Preparation

Select an IPA, certificate and provisioning profile, check that the required inputs are present and export a signing handoff request.

↻

Version Tools

Local File Library

Keep imported files on device, share documents and remove items you no longer need.

ADD THE PLUTO SIGN SHORTCUT
On iPhone in Safari
  1. Tap Add Home Screen Shortcut.
  2. Tap Allow when iOS asks to download the configuration profile.
  3. Open Settings and tap Profile Downloaded.
  4. Review the Pluto Sign profile and tap Install. The updated profile includes a custom Pluto Sign icon.

Signing note: importing your own P12/PFX and profile does not by itself sign an IPA. The iOS app prepares a signing handoff and checks that the selected inputs are present; Apple code signing must be completed in an authorized macOS workflow that verifies certificate/profile compatibility, bundle ID, entitlements and distribution method. The current GitHub Actions artifact is for iOS Simulator, not an iPhone-installable IPA.

The .mobileconfig installs only a removable website shortcut and its icon. It does not install the native app, certificates, VPN or device management.
