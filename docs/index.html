PLUTO SIGN

Home Screen profile

Download the Pluto Sign configuration profile to add a removable website shortcut to your iPhone Home Screen.

Download configuration profile
On your iPhone
  1. Open this page in Safari.
  2. Tap Download configuration profile, then tap Allow when iOS asks.
  3. Open Settings and tap Profile Downloaded.
  4. Review the profile and tap Install to add the Pluto Sign website shortcut.

This profile adds only a removable Home Screen web shortcut to this project page. It does not install a certificate, change trust settings, enroll device management, or make unsigned apps installable. You can remove it later in Settings → General → VPN & Device Management.
