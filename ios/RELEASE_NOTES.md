Pluto Sign iOS source prerelease. Includes SwiftUI IPA manager, archive browser/search, version metadata audit/sync, P12/PFX Keychain import, provisioning profile import, and signing-request export.

IMPORTANT: GitHub Actions currently builds a simulator artifact only. It is not an iPhone-installable IPA. Upload to InstallOnAir only after creating a properly signed device IPA with authorized Apple credentials and a matching provisioning profile.
No private keys, P12 files, passwords, or provisioning profiles are included.
